### Project Description
This is fun — a "Wrongulator" calculator that confidently gives wrong answers and argues with you about it in a chat panel, complete with an animated bot mascot and a peeking character. It looks complete and well put together.Also the mascots will react your offenses by expressions

### The Problem (that doesn't exist)
Standard calculators are functional but forgettable — they take input, return a correct answer, and offer no personality or delight in the process. The challenge for this project was to design a calculator-style web app that subverts that expectation: instead of being a tool for accurate computation, it's a comedic character that performs the role of a calculator while deliberately getting arithmetic wrong, and defends its wrong answers with unwavering confidence when challenged.


### The Solution (that nobody asked for)
We built a calculator with a rigged arithmetic engine (addition concatenates digits instead of adding them, multiplication subtracts, division multiplies, and so on) so every result is wrong in a consistent, "systematic" way. Then we gave it a personality: a built-in chat panel where you can accuse it of being wrong, and it will gaslight you right back with confidence, sarcasm, and mock outrage — complete with an animated mascot that gasps, glares, and rolls its eyes, and a nosy little character that peeks out from behind the chat to react to the drama.


## Technical Details
### Technologies/Components Used
For Software:
- HTML5, CSS3, JavaScript (vanilla, no frameworks)
- CSS animations and keyframes for the mascot, peeker character, and floating math-symbol background
- Regex-based intent matching for the chatbot's responses
- No external libraries — everything is self-contained in static files
For Hardware:-none
